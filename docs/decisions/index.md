# Decisions

Short records of the choices that shaped the tool, each with the alternative
it rejected and what would have to change for the decision to be revisited.
They are written for whoever changes this next — including a model reading
`CLAUDE.md` — because a constraint whose reason is lost gets removed by the
first person who finds it inconvenient.

| # | Decision |
|---|---|
| [0001](0001-three-phases.md) | Three phases, and nothing is written without an approved plan |
| [0002](0002-no-recipe-deletion.md) | No operation for deleting a recipe |
| [0003](0003-one-source-many-frontends.md) | One rule set, rendered into every frontend |
| [0004](0004-index-first.md) | An index, not a loop over the API |
| [0005](0005-guards-refuse-not-warn.md) | Guards refuse; they do not warn |
| [0006](0006-data-not-prose.md) | Mechanical rules are data, not prompt text |
| [0007](0007-changelog-before-write.md) | The before-state is logged before the next action runs |
| [0008](0008-target-current-mealie.md) | Target current Mealie, and refuse outdated payload shapes |

All recorded 2026-08-10, describing decisions made over the life of the
project rather than on that date.
